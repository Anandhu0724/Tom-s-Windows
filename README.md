# Windows 11 Tom Desktop

Open `index.html` in a modern browser.

Features:
- Windows 11-inspired glassmorphism desktop and taskbar
- Uploaded Tom image used as the desktop pet
- Multiple Tom moods, speech bubbles and movement
- Simulated unwanted app openings and notifications
- Paint app with freehand drawing
- Notepad, Calculator, Edge/YouTube-style windows
- Right-click Tom menu
- Optional temporary pointer lock
- Fullscreen after the user clicks Start Tom's Desktop
- Dark Windows 11-style ribbon wallpaper fallback when no local wallpaper asset is available
- Supplied `lockscreen.jpg` wallpaper used by the desktop and lock screen
- Local `pecos.mp4` media available inside the simulated VLC player

Important browser limitation:
This is a website, so JavaScript cannot obtain unrestricted control over the user's Windows OS, keyboard, mouse or other applications. The "permission" system here is intentionally simulated and limited to this webpage. Pointer lock/fullscreen also require a user gesture.
